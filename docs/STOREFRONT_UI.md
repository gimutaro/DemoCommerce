# ストア表示の更新（2026-10-18）

公開ページを通常のライフスタイルストアの表示に揃えました。

- ヘッダー、商品詳細、フッターから検証環境を示すバナーや説明を撤去。
- 旧ワークベンチを会員ログイン、会員情報、資料ダウンロードなどの画面へ変更。
- スタッフ用メニューは `/staff`。一般向けメニューには表示しません。
- パスワードは伏せ字。ログインフォームは空欄から開始。
- 攻撃名、入力例、プリセット、SQL、HTTPステータス、APIパス、実行履歴を画面に表示しません。
- レスポンスは氏名・メールなどの項目別表示に変更。通信エラーは利用者向けの文言に変換。
- 注文画面の比較リンク、認可判定、実装説明を撤去。
- お問い合わせは文字列としての内容確認のみ。送信・保存の成功を装いません。

WorkerのSPAルート一覧に `/contact` と `/staff` を追加しています。既存の検証API、データセット、環境ガード、RLSには変更を加えていません。検証対象の定義や合成データの識別情報はソース・文書・APIレスポンス内に残します。ブラウザの開発者ツールやソースから検証環境であることを隠す変更ではありません。確認書類のSAMPLE・無効表示も維持します。
